# Mindwell
Mental Health website to track mood, journal, assess the behaviour patterns and contact psychologist if needed.

## Stack

- Next.js
- React
- TypeScript
- Framer Motion
- MongoDB

## Run locally

1. Install dependencies:

```bash
npm install
```

2. Create `.env.local` from `.env.example` and set `MONGODB_URI`.

3. Start the app:

```bash
npm run dev
```

4. Open `http://localhost:3000`.
